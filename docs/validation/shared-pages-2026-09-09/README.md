## 关键改动

- 把概览的文字角色抽到共享 tokens：区块标题 18/26/650；正文 14/20/400；辅助文字 13/20/400；表头（包括筛选与排序控件）13/20/650；名称 14/20/550。
- 生产、审核指标取消外围卡片边框，标签与说明图标靠近，待处理数量使用 40px、辅助统计使用 30px。业务值和指标入口不变。
- 交付表合并重复列宽规则，保留全部 11 列。1512px 下完整展示进度和操作；数量列右对齐并使用等宽数字，窄屏支持横向滚动。
- 专家指标改成开放式排列，保留既有风险团队计数与零值，统一区块间距与表头控件。
- 成员管理沿用其他页面的内容边界与留白，名称、邮箱分清层级，搜索框与邀请按钮保持同一工具栏。
- 审核窄屏将两项待处理指标并排，今日已审核另起一行，避免旧三列布局的标签重叠。
