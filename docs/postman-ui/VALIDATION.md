## 尚存问题 / 原型边界

1. 原始统一导出按钮没有业务回调。本版保留位置和计数，禁用并显示“当前原型尚未接入统一导出服务”的提示。
2. 资源字段、真实模型可用性与账单服务尚未接入；账单是明确标注的示例，部分产物和参考资料为空。现有原型的未实现入口仍需后续业务开发。
3. 少数历史审核队列 Item 与运行的 itemIds 归属校验不一致。队列点击可以进入，但直接刷新对应工作台链接可能显示“这个 Item 不属于链接中的审核运行”。保留数据归属校验，不做放宽；该问题来自本轮期间新增的原型路由层。
4. 浏览器已覆盖主要交互和上述窗口；未声称每条数据、每个弹层组合、真实上传、所有辅助技术和后端集成均经过验证。
