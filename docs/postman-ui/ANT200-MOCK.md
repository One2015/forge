审核分配可切换按 Item，每页 20 条，共 10 页，支持名称与 ID 搜索。生成模块为 `scripts/postman-ui/ant200-mock.mjs`；`scripts/test-postman-ui.mjs` 覆盖数量、唯一 ID、汇总一致性、状态变更及搜索末项。
