# 数据单草稿

创建数据单页保留原有纵向表单与底部操作栏，新增次级「保存草稿」，不要求必填信息已完成。

- 交付页「草稿」分组可继续编辑或确认删除，不计入正式单数量、进度或成员通知。
- 手动保存后留在表单，显示保存时间；继续修改显示「有未保存的修改」。没有自动保存。
- 返回或切换页面时可继续填写、不保存离开、保存草稿并离开。丢弃修改不会删除此前保存的版本。
- 正式创建仍执行原有完整校验；创建成功后仅移除对应草稿。移除失败会保留记录并提示，不能静默覆盖另一页面的新版本。
- IndexedDB 数据库 `forge-delivery-drafts`，记录以 `[owner, id]` 为主键，按当前演示账号隔离。仅当前浏览器、当前站点来源有效，不是服务端授权或云同步。
- 保存表单字段、成员角色、List 条目与原 ZIP File/Blob、Logo 数据、Tag 与未完成 Tag、已选 Skill 快照、尚未发布的 Skill 表单/上传文本。只保存数据，不执行上传指令、不发布 Skill。
- 正式数据单、通知以及独立平台 Skill 仍沿用原来的会话演示状态；本次只持久化草稿。
- 保存和删除使用事务内版本检查；冲突保留当前输入并提供「另存为新草稿」。配额/存储限制/读取错误均有重试提示。成功提示仅在事务提交后出现。
- 已读取附件保留；文件仍在读取时暂不允许保存。保存期间防止重复保存、正式创建或离开；期间新增输入不会被标记为已保存。

## 修改入口

`scripts/templates/delivery-drafts.{js,html,css}` 与现有 `delivery-methods.js`、`delivery-create-page.js`、`delivery-editor.html`、`render-delivery-editor.mjs`。

定向同步：`node scripts/update-delivery-drafts.mjs`。不要重放全部旧迁移。

## 验证

`scripts/test-delivery-drafts.mjs` 覆盖不完整/未命名保存、跨组件恢复、Blob 内容保留、更新与多个草稿、离开路径、上传与保存竞争、配额失败、账号隔离、版本冲突、确认删除、成功创建后清理、损坏记录以及迁移幂等。

浏览器实际验证了保存、刷新恢复、已选 Skill、保存后离开、双页面版本冲突和桌面/390px 新增控件布局。附件恢复与存储配额失败由自动化状态测试验证；未通过浏览器制造配额耗尽。既有窄屏正式数据单卡片布局不属于本次修改。
