# 用量与费用（本地原型）

入口：概览 →「昨日成本」。四个分析入口为总览、按项目、按供应商、按模型，分别有 `/billing/overview`、`/billing/projects`、`/billing/suppliers`、`/billing/models` 路由。总览默认呈现项目费用来源。时间、项目、供应商、模型统一筛选；快捷时间直接更新范围，自定义时才显示日期输入。粒度紧邻主趋势图。

四项 KPI：总费用（与上一等长周期对比）、总 Tokens（输入／输出构成）、调用次数（平均 Tokens）、平均调用成本。主图可切换费用、输入／输出堆叠 Tokens、调用次数；补齐零值桶。Radix tooltip 提供完整时段明细，键盘聚焦也可读取。点击时段后 KPI、费用来源、表格、导出明细同步筛选，主图保留完整范围。

明细支持所有数值与名称双向排序、搜索、分页、CSV 导出、行点击下钻及返回上一级。项目下钻供应商、供应商下钻模型、模型下钻项目；切换分析维度保留当前筛选，支持查看其他分布。筛选可独立移除，也可重置；搜索只缩小明细行，不改变费用占比分母。

顶部「导出明细」导出当前筛选下的调用事件；表格「导出 CSV」导出搜索结果的全部汇总行（不是仅当前页）。CSV 含 UTF-8 BOM、示例标记和六位小数 USD 金额，正确转义双引号／换行并防止表格公式注入。全部在本地生成，不请求外部 API。

## 数据与口径

- 昨日是北京时间 UTC+8 的自然日 `[昨日 00:00, 今日 00:00)`，不是过去 24 小时，也不是昨日创建的运行的全生命周期费用。
- 页面结束日期包含当日；后端事件以费用发生时间归属。小时／日／月／年只改变趋势聚合粒度，不改变筛选总额。
- 「近 12 个月」为最近 12 个完整自然月，不包含本月未完结的部分；例如 2026-09-03 查看的是 2025-09-01 至 2026-08-31，共 12 个按月聚合区间。
- 只展示 USD 模型调用成本。账单金额由数据源提供，不通过公开价目表、运行费用或调用次数反推。失败调用产生费用时仍应计入。不包含充值、税费、人工成本或套餐购买。
- 总 Tokens = 输入 + 输出。输入若含缓存 Token，不应再把缓存 Token 加一遍。当前没有缓存折扣明细、发票、支付或费用预测。
- 项目使用 `projectId`，供应商使用 `providerId`；模型使用 `[brandId, modelId]` 联合键。代理商与模型品牌是不同维度。
- 目前用户已批准使用明确标注的合成示例：页面与概览卡片共用示例事件，不是真实账户消费。示例模型名称不是可用性或实时单价声明。

## 接入边界

`Component.props.billingUsage` 是预留输入，不是已经连通的后台 API。

| 输入 | 展示 |
| --- | --- |
| 未提供（`undefined`） | 本地合成示例，显示「示例数据／示例账单」 |
| `null` | 待接入，金额显示 `—` |
| `{ status: 'loading' }` | 加载中，不显示假零值 |
| `{ status: 'error' }` | 读取失败，不显示残缺汇总 |
| ready、完整、合法的空账单 | `$0.00` 与无记录状态 |

**上线时必须显式传入真实账单或 `null`，不得依赖缺省示例。** 接入前确认组织时区、币种和账单覆盖范围；本原型固定为 UTC+8 / USD，不做换汇。真实数据量大时应由服务端按相同口径聚合、分页，当前事件级演示不代表生产查询能力。

```js
{
  status: 'ready',
  currency: 'USD',
  complete: true, // 输入是完整账单，而非部分分页结果
  coverageStart: '2026-08-01T00:00:00+08:00', // 可选；账单历史覆盖起点，包含
  coverageEnd: '2026-09-03T12:00:00+08:00', // 可选；覆盖终点，不包含
  updatedAt: '2026-09-03T11:59:00+08:00', // 可选；数据更新时间，而非页面渲染时间
  events: [{
    id: 'usage-unique-id',
    occurredAt: '2026-09-02T10:15:00+08:00', // 或毫秒时间戳
    projectId: 'web3d', projectName: 'Web3D 中国地标',
    providerId: 'vendor-a', providerName: '供应商 A',
    brandId: 'brand-a', brandName: '品牌 A',
    modelId: 'model-a', modelName: '型号 A',
    inputTokens: 1000,
    outputTokens: 250,
    costMicros: 2500000 // 整数 USD 微元；本行示例为 $2.50
  }]
}
```

ID 与名称不能为空；时间必须有时区且不晚于当前时间；Token 与金额必须是非负安全整数。相同 ID 的完全重复记录去重，冲突记录、目录名称冲突、缺失或非法数值会使整个输入显示错误，避免静默低估。更新时传入新的输入对象，验证缓存按对象引用更新。

上一周期为紧邻当前起点之前的等长时段，使用同一维度筛选。覆盖元信息缺失或不足时显示「上一周期数据不足」，不将缺失视作零。零基期显示「本期新增」，不输出无穷大。今天截取至当前时刻；月／年首尾桶仅统计范围内日期，桶比较为上一等长时段而不是隐含整月环比。

费用变化分解：调用量贡献 = (本期调用数 − 上期调用数) × 上期平均成本；单次成本贡献 = 本期调用数 × (本期平均成本 − 上期平均成本)。后者可能来自单次用量或模型组合，不声称是供应商调价。未接入预算／异常阈值，不把增长自动标记为事故；提供增幅和最大费用增量来源供判断。

## 维护与验证

- HTML / CSS / 逻辑：`scripts/templates/billing.html`、`billing.css`、`billing-methods.js`。
- 卡片入口：`scripts/templates/overview-summary-methods.js`。
- 修改后运行 `node scripts/update-billing.mjs`，再运行 `npm test` 与 `npm run build`。同步脚本只更新指定片段并保持幂等，不应重放全部历史迁移。
- 当前模板属性只支持简单绑定：预先计算 ARIA 状态值，不在属性插值中写三元表达式。动态 `<sc-for>` 不能放入原生 `<tbody>`，所以明细使用完整 ARIA table/rowgroup/row/cell 语义与 CSS Grid。
- 原生日期输入通过 `input` 更新，原生下拉通过 `change` 更新。日期错误提供「恢复昨日范围」；小时最多 7 天、日最多 366 天，长范围使用月／年。
- 图表柱可点击或键盘 Enter 选择，显示可清除的时段标签；键盘焦点可见。窄屏图表、表格独立横向滚动，不撑开整页。指标标题旁的信息图标支持悬停、键盘聚焦和点击查看对应口径。
- 分享链接保留筛选、指标、粒度、时段、排序、搜索和分页；搜索输入使用 history replace，避免每个字符增加历史条目。

浏览器验收与限制见根目录 `VALIDATION.md`。
