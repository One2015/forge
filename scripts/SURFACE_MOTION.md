## 分段控件与标签

选中背景或下划线在 160ms 内移动；不移动文字、不延迟内容更新。

- Pipeline：活跃／全部／废弃。
- 运行任务：状态筛选。
- 审核队列：全部／我的。
- 交付列表：全部／Web3D／Vision2Web／金融／WebDev。
- 数据单：全部／可交付／待审核／运行中。
- 导入数据集：导入方式。
- 生产二级导航：运行任务／Pipeline／数据集／资源。
- 个人工作区：任务／Skill。
- 数据单编辑：基础信息／List 与 Tag／Skill。
- 关联任务：关联已有 Item／创建新 Item。
- 产物查看器：预览／文件列表（独立 React 根同样覆盖）。

## 下拉菜单

160ms 进入、120ms 退出；靠触发按钮的一侧作为缩放原点。

- 交付列表排序。
- Pipeline 编辑中的数据集选择。
- 数据集详情的版本选择。
- 数据单成员搜索结果（原生 popover）。

原生 select 的选项面板仍由操作系统和浏览器绘制，不替换原生选择交互。

## Cover 与 hover / press

- 审核队列封面、关联 Item 缩略图和可点击参考图：鼠标悬停时轻微放大 2%。
- 按钮：120ms 颜色反馈。
- 主要操作按钮和关闭按钮：按下时轻微缩小 2%。

触屏不使用封面悬停效果。键盘切换和 Escape 不等待动画；减少动态效果时，本轮弹窗和菜单变为 90ms 淡入淡出，移除位移与缩放，分段指示器直接切换。

原有下载、通知、个人工作区和更换关联任务的动画继续保留。

## 页面、列表、Toast 与拖拽反馈

- 页面切换：概览、生产、审核、交付及详情页采用 160ms 淡入。内容立即可操作；连续切换会从当前透明度接续。
- 列表更新：Pipeline、运行任务、数据集、数据集 Item、交付卡片、数据单 Item、待审核及审核结果。新增行短暂淡入；筛选或排序后，保留的条目按真实记录身份移动到新位置。一次最多动画 24 个可见条目，较远的位置变化改用局部淡入。
- 页面进入时不叠加列表入场；没有条目变化的普通状态更新不会重播。键盘筛选即时更新，减少动态效果时仅保留 90ms 淡入。
- Toast：审核结果提示与右下角操作提醒，180ms 进入、120ms 退出，伴随 8px 上移；退出时保留文字，连续通知可立即接续。减少动态效果时改为 90ms 纯淡入淡出。
- 按钮：扩展到上传、下载、审核、取消、侧栏和产物工具按钮的按压反馈。选中状态按钮继续使用已有的背景滑块反馈。
- 数据集分隔条：悬停时握柄变色、略微变宽，抓取时加强，松手后回到默认外观。实际宽度仍与指针 1:1 对应，释放不漂移。减少动态效果时只变色，键盘仍直接调整宽度。

复查路径：点击几个主导航 → Pipeline 在“全部／活跃／废弃”间快速切换 → 交付排序 → 交付“蚂蚁 Web3D 首批 200 条”里的“长城”详情，点击“下载已通过版本”触发本地演示提醒 → 生产“数据集”拖动中间分隔条。

## 维护与验证

新增 CSS 和状态保留逻辑位于 `scripts/templates/surface-motion.css`、`surface-motion-methods.js`；分段控件的 DOM 适配位于 `scripts/surface-motion-runtime.js`。

文字型分段选项使用同一 Grid 单元叠放可见文字与隐藏的粗体宽度占位。同步器会移除旧按钮的内联 Flex／gap／文字对齐属性，避免隐藏占位被当成第二个横向元素而撑宽按钮；当前运行页的独立控件不受影响。

依次执行 `node scripts/update-surface-motion.mjs`、`node scripts/update-flow-motion.mjs` 同步到页面。修改其他历史模板后，也应执行此同步；更新器是幂等的。原生弹窗和标签的标记同步保存在对应源模板中。

页面和列表动画由 `scripts/flow-motion-runtime.mjs` 驱动，使用浏览器动画 API，不逐帧更新应用状态。

验证：314 项自动检查通过，生产构建通过；浏览器复查了分段选项、排序菜单、Pipeline 上传、数据单编辑、Skill 嵌套弹窗、Item 详情、审核确认、分支窗口、快速重开和 Escape。另复查了页面切换、列表快速筛选、Toast 连续触发/关闭、分隔条 45px 拖动与键盘 10px 调整。减少动态效果通过逻辑测试覆盖；未更改用户系统设置进行设备级验证。
