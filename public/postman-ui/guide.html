页面与导航

全局工具条高 40px；模块侧栏宽 176px，收起后 56px。生产模块使用 40px 二级标签。主内容横向留白通常 24px，标题与对象操作同层。选中模块即时呈现，常用导航无需等待动画。

页面模式实现规则
列表 / 交付客户分组条 + 连续行。对象名称、计数、履约进度和入口对齐；避免为每条数据增加一层卡片。
数据单详情代表页面。标题/任务操作 → 履约指标带 → 筛选/搜索 → Item 列表。目标、已关联、已跑完、待审核、可交付的含义保持不变。
数据集资源列表和 Item 详情并列，详情默认 660px，可用键盘或拖动调整；≤1100px 改上下分区。
审核 / 产物详情保留最大可用预览面，右侧依据和活动记录约 392px。判断按钮固定于任务区底部；无文件时显示真实说明。
创建 / 编辑创建使用完整页面，编辑沿用三标签弹窗。必填标识、输入提示和保存/取消位置一致；保留成员、List、Tag、Skill 与草稿逻辑。
画布保持节点、连线、缩放和节点检查器。画布为中性点阵；节点使用白底、1px 中性边框和 4px 圆角，类别色只用于标记与进度。
分析统一汇总数字、轴刻度、浅网格、图例与读数区。图表保留现有可键盘选择的数据柱及筛选联动。

表头与局部控件

表头和分组头统一 #FAFAFA 中性浅灰底，#696969 文字，#E9E9E9 细分隔线。二级按钮白底灰边，三级操作透明底灰字；hover 统一 #F7F7F7，边框加深至 #999999。生产、费用、编辑 tab 和分段筛选选中均为纯白底、#525252 的 1px 指示线或内描边。橙色用于全局导航，黑色用于主 CTA。

排版、密度与状态

项目规则
中文字体系统 UI 字体，PingFang SC → Hiragino Sans GB → Microsoft YaHei 回退；正文不依赖额外字体下载。
字号页面标题 20/28px、分区标题 14–15px、正文 13/20–21px、辅助 12/18–20px。字重通常 400/500/600。
数字与标识数值使用等宽数字；ID/版本可使用等宽字体。金额保留 USD 与两位小数，数量/Token 保留分隔符和单位。
控件常规高 32px，紧凑 28px；触控窗口尽量使用至少 44px 目标。图标 16px，主导航 18px。
边界控件圆角 4px、浮层 8px。连续区域优先分隔线；只有独立任务单元使用容器。阴影留给覆盖层。
交互hover 极浅中性灰 #F7F7F7，控件边框加深至 #999999、保持 1px；selected 纯白底，配合边框或指示线；主导航纯白底与橙色图标/定位条；focus-visible 统一深灰 #525252、1px 细线；输入框焦点线与边框重合，避免双圈；仅供滚动定位的页面分区不显示整块焦点框；disabled 不仅变色，还使用真实禁用属性；不伪造加载百分比。
长内容 / 窄窗口标题和描述允许合理换行，稳定 ID 用截断/完整可访问文字；宽表局部滚动。390px 是适应性检查，不把专业画布强行塞成小卡片。

统一状态与操作等级

审核队列使用“待审核／审核结果”一级 Tabs；“全部／我的”移入审核范围筛选。摘要按实际任务计算，六列表格统一任务、类型、轮次、人员、时间和操作。首次审核黑色主按钮，复审浅橙，继续审核浅绿，查看进度／结果中性描边；绿色仅表达正在审核的正常工作流。普通背景、hover 和选中区域保持中性。

所有页面的状态标签使用白底、1px 细边框。运行成功与审核通过分别保留业务含义：运行已成功、但 Item 尚待审核时，成功标签为绿色，待审核指标与进度仍为琥珀色。

实现：states.css 管理语义状态，controls.css 管理操作等级；semantic-colors.mjs 将旧展示绑定接入共享 tokens，保留业务方法。

运行记录

五张轻量 Summary 高 78px，白底灰边 8px 圆角，所有数字黑色。运行记录使用 70px 连续行，数据集置于运行信息第三行。运行完成与失败 Item 分别表达。查看详情中性，失败项橙边，原因红边，去审核浅绿；其余操作收进灰色更多菜单。筛选和分页同步；小屏采用局部横向滚动。

实现入口

public/postman-ui/tokens.css 管理共享变量；workspace.css 管理工作区和兼容规则；pages.css 管理已验证页面模式；behavior.mjs 为已有点击容器补足键盘操作。

主要旧页面使用稳定的 pm-page-* 钩子；Pipeline 节点使用 pm-pipeline-node 与 data-node-kind，避免依赖文案或行内颜色定位页面。

scripts/postman-ui/build.mjs 从当前原型定向生成 public/forge-postman.html，不回写原版。运行 npm run dev:postman，打开 http://127.0.0.1:3011/forge-postman.html。默认开发脚本仍服务原版，避免两个评审入口互相覆盖。

当前是本地可操作原型。统一导出、资源结构与真实监控尚未接入；账单明确标为示例。部分历史审核 Item 的直接链接可能被原型归属校验拒绝，可从审核队列进入；未放宽数据校验。评审阶段保留独立入口与分支，不部署、不合并。
