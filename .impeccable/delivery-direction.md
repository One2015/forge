# Delivery creation and review skills · Operate

Local extension. Preserve existing navigation, delivery metrics, review decisions, compact tokens and Phosphor icons. User approved a Skill invocation demonstration, not an evaluation engine. List accepts ZIP or pasted text. Uploaded instructions are inert data, never automatically executed. State remains session-local and is labeled accordingly.

## Direction contract

THESIS: Configure a delivery sheet once; expose its uploaded review skills only to related Items and Runs.

OWN-WORLD: Inherit white panels, restrained orange actions, 13–14px Chinese sans text, 18px dialog heading and 6px controls.

STORY: Create or edit basics, inspect List entries and colored Tags, attach skills, then invoke a bound command during review.

FIRST VIEWPORT: A compact native dialog with three tabs, scrollable fields and fixed save/cancel actions. Review gets an inline skill command field and explicit demo results.

FORM: Precisely specified local extension; no seed required. Required fields, file loading, invalid List input and invalid/duplicate Skill commands gate submission. Rejected optional Logo/Skill files show errors and are not added. No new visual identity or generated raster.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
