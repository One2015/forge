# Forge 创建数据单 · 四步流程

本轮按 Impeccable 的 Operate / distill 原则整理任务层级，保留现有侧边栏、字体、暖白背景与 Forge 橙色。此记录取代此前的连续长表单说明；已有数据单的编辑弹窗保持不变。

## 结构与视觉

- 路由为 `/delivery/new`，四步对应 `#basic`、`#list`、`#skills`、`#confirm`。步骤访问必须经过当前表单校验，URL 不可绕过校验。
- 四步依次为基础信息、导入 List、配置规则、确认创建；仅挂载当前任务，已完成步骤可返回修改。
- 最大内容宽 1120px；右侧配置摘要宽 272px，紧凑桌面为 260px。820px 以下改为顶部可展开摘要。
- 22px 页面标题、16px 步骤标题、14px 卡片标题、13px 表单正文；复用应用字体与颜色变量。
- 当前步骤使用浅橙底与橙色编号；其他步骤保持轻量，完成状态不依赖颜色。
- 轻边框与 8px 圆角卡片，无渐变或大阴影。固定底栏展示前进/后退操作和明确的阻塞原因。
- 移动端表格行改为两列布局；Tag 与删除操作位于行内第二排。操作栏换行且不超出页面。
- 切换步骤回到流程顶部，焦点移至当前任务标题，不使用滚动动画。

## 数据与校验

基础信息要求名称、客户和 1–500 的整数目标。Logo、说明选填。目标表示本单需要交付的有效 Item 数量。

List 默认粘贴输入。ZIP 与粘贴是互斥输入模式，切换保留两份输入而不混合。ZIP 继续复用大小、路径、压缩包解析安全检查，不执行文件。

解析保留每条来源：唯一精确匹配到目录名称或 Item ID 的条目才计为有效；名称/ID 别名重复、格式错误与未匹配均可见。不再静默去重。目标与有效数量不一致、存在异常、读取中或解析错误时不能继续。可逐条删除、只看异常、修改原文或明确将目标调整为有效数量。每页 8 条并显示范围。

默认 Tag 应用于全部 Item；单条可覆盖或明确选择“不使用 Tag”。新建 Tag 自动成为默认 Tag。Skill 可按名称、调用名、描述及类别筛选，已选固定在顶部，最多 12 项，整行选择与查看详情相互独立。「创建 Skill」复用编辑弹窗的原生 Popover，提供「填写表单」和「上传文件」两个入口；上传支持 .md 或含 SKILL.md 的 ZIP，读取后仍需明确确认创建。原生控件负责关闭和键盘操作，选择入口后现有处理逻辑关闭菜单并聚焦对应输入区。两种方式间切换保留未完成内容和数据单配置；已创建 Skill 不因退出本单被删除。按钮、图标和菜单沿用现有样式，不新增依赖。

最后一步集中核对配置并编辑成员。角色权限仅对本单生效，Owner 显示为“所有者”；唯一所有者不能移除或降级。最终提交再次校验所有步骤、成员和当前账号。

## 数据保留边界

步骤切换保留当前内存内容。创建流程没有保存草稿、自动保存或相关提示；离开时仅提供继续填写/离开。此前浏览器中已有草稿没有被删除，既有草稿存储与编辑功能未被破坏。正式记录与提醒仍沿用本地演示实现，未增加后端或外部消息发送。

## 源码

- `scripts/templates/delivery-wizard.html`：四步内容和底栏。
- `scripts/templates/delivery-wizard-summary.html`：桌面与移动端共享摘要内容。

- `public/forge.html` 为生成产物，勿单独手改。
