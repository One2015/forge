# forge 人工审核优化 v1.0

Forge 人工审核页面重构：待审核 / 已审核两个模块。

## 文件
- `index.html` — 离线单文件版本，双击即可打开，可直接用 GitHub Pages 托管
- `HumanReview.dc.html` — 源文件（需与 `support.js` 同目录）
- `support.js` — 运行时

## 本版要点
- 待审核：Section 分组 + 带 Preview 的横向卡片，展开后头部收敛为紧凑 Header
- 审核决策：先选「通过 / 要求返工」，不预选；返工要求必填，支持最多 8 张参考图
- 已审核：横向摘要卡片 + 竖向轮次 Timeline，最新一轮默认展开
- 支持停止正在执行的返工、基于任意历史轮次重新发起返工
- 顶部工具条：case 名称 / 编号关键词搜索、「只看我的」、最新 / 最旧排序下拉
